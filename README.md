
# Grocery List PWA

A responsive grocery-list progressive web app built with Next.js, React, and TypeScript.

## Features

- Organize grocery lists by store.
- Assign aisle information to items for more efficient shopping.
- Designed for a responsive, mobile-friendly experience.

## Technology

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

Build the static site:

```bash
npm run build
```

The generated static website is written to the `out` directory.

## Deployment

The project is configured for static hosting on Cloudflare Pages. Changes pushed to the `main` branch trigger an automatic deployment.
